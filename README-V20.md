# Web Factory V20 — Proposal CTA Modal

V20 changes the primary proposal CTA from an in-page anchor into an explicit lead-form modal. The existing inline form and `/api/proposal-leads` flow remain available.

## Run
npm install
npm run dev

Open `/proposal/<slug>` and click **Quiero esta web**. A modal opens immediately with the contact form.

No new environment variables or database tables are required beyond V19.
