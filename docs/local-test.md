# Local test checklist

1. `npm run dev`
2. Open `http://localhost:3000/` for the default generated site.
3. Open `http://localhost:3000/auto` to see deterministic automatic design selection.
4. Open `/playground?layout=L1`, then change L1 to L2, L3, L4 and L5.
5. Compare which layout feels best for a real local plumber.

The next milestone is to add a business-data form and an AI Design Director that outputs the same `DesignSpec` contract.
